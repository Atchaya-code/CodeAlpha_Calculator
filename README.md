# 🧮 CodeAlpha Calculator

A simple and interactive calculator built using **HTML, CSS, and JavaScript** as part of the CodeAlpha Frontend Development Internship.

## 📌 Project Overview

This project is a basic web-based calculator designed with a clean and user-friendly interface. It performs basic arithmetic operations and provides instant results.

## ✨ Features

- Addition (+)
- Subtraction (-)
- Multiplication (×)
- Division (÷)
- Percentage (%)
- Clear (AC) button
- Delete (DEL) button
- Real-time calculation
- Keyboard support
- Responsive design
- Smooth hover effects and transitions

## 🛠️ Technologies Used

- **HTML5** – Structure of the calculator
- **CSS3** – Styling and layout
- **JavaScript** – Calculator functionality

## 📂 Project Structure

```text
CodeAlpha_Calculator/
│
├── index.html
├── style.css
└── script.js
```

## 🚀 How to Run

1. Download or clone this repository.
2. Open the project folder.
3. Double-click `index.html`.
4. The calculator will open in your web browser.
5. Start performing calculations!
